# Changelog

All notable changes to the CE-RISE Uncertainty Quantification Data Model will be documented in this file.

## [0.0.2] - 2026-05-12

### Fixed
- Namespaced LinkML class, slot, and enum identifiers that conflicted with the metrological traceability and data quality framework utility models when imported together.

## [0.0.1] - 2026-05-08

### Added
- Initial project structure for the CE-RISE Uncertainty Quantification Data Model
- LinkML model structure for uncertainty statements, measurands, distributions, intervals, budgets, components, propagation analyses, scenarios, comparisons, and evidence references
- Repository metadata for Codeberg Pages, Zenodo, citation, and GitHub release mirroring
